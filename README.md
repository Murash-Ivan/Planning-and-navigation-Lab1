# Lab-1

Лабораторная работа №1: Управление мобильным роботом в симуляторе IoTRobotWorld

Реализовано приложение на C# (Windows Forms) для управления роботом в симуляторе IoTRobotWorld по протоколу UDP.

Основные функции:
- Сетевое взаимодействие по UDP с многопоточной обработкой данных
- Ручной парсинг JSON без сторонних библиотек (согласно требованиям задания)
- Ручное управление через интерфейс и клавиатуру
- Автоматическое управление по алгоритму (наивный алгоритм, движение по таймеру)
- Циклограммное управление на основе таймера
- Калибровка фаз движения для объезда 4 препятствий

Технологии: C#, .NET Framework, WinForms, UDP, многопоточность
